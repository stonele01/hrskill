# 薪酬试算与发薪前复核

改编自 Anthropic payroll-prep 的周期核对、逐人异常、前期比较和复核表流程；移除国外默认加班规则、发薪系统写入和记账动作。见 [来源](references/source.md)。

## 所需输入

工资周期、人员名册及工号、已批准薪资与生效日期、考勤和已批准请假、绩效/提成依据、公司计算规则及版本、工资模板；上期工资用于比较。用户只给一部分时可完成资料检查，但不得把不完整试算标成最终工资。

直接复用既有 Excel 模板与表格 Skill/工具，不自建工资引擎、不更换薪酬系统。工资、社保、公积金、税额等缺少经确认的数值/规则时标“待核实”，不凭常识补公式或套国外税制。涉及法规解释或判断扣款是否合法，另行查当前官方规则并交专业人员确认；本 Skill 的试算不能证明规则合法。

## 核对与计算

1. 固定公司/团队、周期、截止时点和人员范围。对入离职、调薪生效、跨月、转正、请假单列；用工号连接各表，同名不能强连。缺名册者不直接加入工资汇总。
2. 校验重复考勤、重叠班次、缺卡、未审批请假、单位不一致和跨周期数据。缺卡不补成正常上下班；异常要列具体人员、日期、来源，不悄悄修正。
3. 对每个工资项目记录 `输入值＋来源＋批准规则＋公式＋结果＋状态`。绩效未确认不按满额或零发处理。不得凭“常用”默认日薪除数、加班倍数、税率、比例或四舍五入时点。
4. 用表格公式或确定性计算工具计算，不靠模型心算。金额精度、舍入方式、各项目是否逐项舍入按已确认规则；未确认且影响结果时停止对应项目的最终数值。
5. 保持 `已确认小计`、`未确定项目`、`完整试算总额` 分开。任一项目未知，就不能把已知项小计叫实发工资。税扣缺失时只能给已确认项目或应发口径，不能宣称税后实发。
6. 与原工资模板、上期按工号逐项对比，列差额和可证实原因。历史不在场时写“未做前期比较”。是否为异常按公司阈值；没阈值展示变化，不发明合规结论。
7. 对每个人每项异常记录负责人决定、依据和复核日期。修订产生新版本，不覆盖原表，不用一次“都确认”掩盖未解决事项。

## 输出与验收

输出新的 Excel 复核表：`周期与规则`、`人员核对`、`工资项目明细`、`逐人汇总`、`异常待确认`、`前期差异`。注明“试算/复核稿，非发薪指令”。对工资表的读取和共享仅限授权范围，汇总隐藏证件、银行卡和不必要联系方式。

验收：人员数量对上；明细合计与汇总相等；未知未当 0；公式无除零或错误引用；抽查入离职、调薪和缺卡案例；回读输出确认公式结果。未执行银行操作、发薪提交、税务申报、工资条群发或正式账簿写入。
