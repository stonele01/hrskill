# 向 HR / 用人主管澄清需求

## 方法与目标

把“公司为什么需要这个岗位”转成能在简历、面试或工作样本里验证的标准。借鉴岗位分析、关键事件访谈、行为锚定和能力取舍；这些是组织心理学与人员甄选方法，不是临床心理诊断，也不是已经验证过效度的心理测验。来源见 [source.md](source.md)。

先看 JD 和已有回答，只问会改变评估的问题。默认先选 3–5 个，按回答补问；不要将下面的问题一次全部发出。没有答案时记录缺口。HR 不清楚业务问题时指出需要哪位用人主管补充，不替主管编造目标。

## 选题顺序

### 一、公司为什么招、成功是什么

- “这个岗位现在最需要解决的一个业务问题是什么？如果三个月招不到，会影响哪项工作或结果？”
- “入职三个月，你看到哪两三项具体成果，会认为这次招对了？目前的基线、目标、期限分别是什么？”
- “这些成果里哪些是他能直接控制的？公司会给什么资源、权限和协作支持？”

作用：识别真正的岗位使命；区分个人可控结果和团队/市场因素。三个月只是提问起点，可随岗位调整，不擅自设销售额或 KPI。

### 二、日常工作和能力缺口

- “这个人一周主要做哪三件事？大约各占多少时间？团队目前最缺哪一块能力？”
- “需要他独立从零搭建，还是按现有流程稳定执行？遇到哪些事可以自己决定，哪些必须请示？”
- “上手第一天必须会什么？哪些允许入职后学习，公司能给多久、什么支持？”

作用：把职位名称还原成真实任务，区分必要条件与可培养项；防止把所有优势都列成一票否决条件。

### 三、关键事件：把抽象词问成行为

- “请讲一件这个岗位最近做得特别好或特别糟的具体事：当时发生了什么、当事人做了什么、结果怎样？”
- “你说‘责任心强’，在这件事里具体希望他做什么？什么时候做，做到什么程度算达标？”
- “你说‘沟通好’，主要是向谁解释什么、协调什么分歧？请给一个真实场景。”
- “你说‘抗压’，实际面对的是多任务冲突、客户投诉还是紧急故障？希望看到什么应对动作？团队有什么支持？”

作用：形成可观察、可评分的工作行为。避免把紧张、口音、语速、外向程度、服从个人偏好或无条件加班当作能力证明。

### 四、用取舍识别真正优先级

- “如果只能优先保证一项：业务经验更深，但需要指导；或能独立分析解决问题，但行业经验少，你更倾向谁？为什么？”
- “JD 写了五年经验。如果有人三年经验但独立完成过同规模任务，你会考虑吗？五年这个要求实际想保证什么？”
- “业务能力强但需要培养哪项能力，你可以接受？哪项工作能力缺口会直接影响履职，不能等入职后再补？”

每次使用与岗位有关、条件平衡的假设，不指名当前候选人、不诱导选择；允许用户回答“两者都不合适”。答案用来确定条件等级和权重，不凭一个偏好推算心理特征。

### 五、公司能提供什么、有哪些现实约束

- “岗位的地点、班次、出差、薪酬区间和到岗时间里，哪些已确定、哪些可协商？”
- “绩效好的人在你们团队通常怎样协作、接受反馈、处理分歧？请给行为例子。”
- “HR 和用人主管对成功标准是否一致？如果不一致，争议具体在哪一项，由谁最终确定？”

作用：识别人岗与工作环境的匹配。薪酬和安排属于双方约束，不因候选人要求更高就扣能力分；所谓‘文化匹配’必须落到工作行为，不能等同于背景相似或‘合眼缘’。

## 追问规则

- 先记录用户原话，再写解释；每项标准注明来源：JD / HR / 用人主管 / 待确认假设。
- 对“能力强、主动、稳定、聪明”等词，追问事件、期望动作、可观察结果；不把标签直接放入评分表。
- 用具体事件检验回答，也追问其他解释，例如表现不好是否缺资源、权限或培训，不能把制度问题都归因于人。
- 避免诱导题如“我们这么重视责任心，你也认为最重要吧？”；也不凭 HR 的说话方式推断其心理状态或管理人格。
- 初筛后新增条件必须解释业务原因，并对整批候选人一致复筛。不得为喜欢的候选人放宽、为不喜欢的候选人收紧。

## 用人需求卡

按以下结构汇总，明确已经确认和仍未知的项目：

| 项目 | 内容 |
|---|---|
| 岗位使命 | 为解决什么问题，在什么期限交付什么结果 |
| 关键成果 | 结果、基线、目标、期限、可控范围、核验方式 |
| 实际工作 | 主要任务、工作量、独立程度、协作对象 |
| 必备 / 可培养 / 加分 | 每项理由与可接受的替代证据 |
| 工作环境与约束 | 资源、权限、班次、薪酬、地点、到岗时间 |
| 评估标准 | 维度、行为锚点、权重、简历/面试/工作样本验证方式 |
| 分歧与确认 | HR 与主管差异、确认人、日期、规则版本 |

每个评估维度形成一条链：**公司目标 → 真实任务 → 所需能力 → 可观察行为 → 证据 → 分数**。

## 一个示例（示例不是默认权重）

HR 原话：“要有责任心、能独立做投放复盘。”

追问：“如果发现消耗上升但订单下降，你希望他先核对哪些数据、什么时候告知负责人、可以自行做哪些调整？”

若 HR 回答“当天检查归因和转化链路，分清素材/人群/落地页原因，小额验证，超过预算调整权限先报批”，就形成维度“异常诊断与处置”。面试进一步核验他是否做过类似任务、本人采取什么行动、依据什么数据，以及效果如何；不能仅因简历写了‘负责投放’就判定达标。
