# 绩效材料收集与证据归档

改编自 Anthropic performance-review 的目标、完成情况、证据结构；聚焦材料整理，不继承默认评级比例和薪酬建议。见 [来源](references/source.md)。

## 输入与复用

接收员工名册、收集周期、已约定的 KPI/任务口径及材料；优先沿用已有台账、模板、文件夹和表格工具。没有必要建立绩效管理系统。线上日志或表格仅通过已连接、已授权且确有读权限的工具读取；不因“收集”而自动群发催办。

## 工作流

1. 确定员工 ID、统计周期、指标 ID/名称、目标值、单位、来源要求和确认状态。未定义指标先列问题；不能把活动数、产出数、业务结果混为一谈。
2. 每条材料保留事件发生时间、提交时间、来源文件/表/行、材料版本、员工和指标映射。晚交材料按真实发生期归档，并单列晚交状态，不移动业绩来填某月空缺。
3. 识别“同一成果在周报、月报重复出现”和“确实是不同成果”。优先用业务单号/任务 ID；无 ID 时标疑似重复供复核，不靠文字相似直接删除。共同完成的项目标出各自贡献证据，不自动平均分。
4. 区分自述、主管确认、系统数据、正式审批。自述数字可以收录，但不能升级成已确认成果。对冲突列出双方数值、口径、周期和来源，待负责人确认。
5. 仅按已批准公式算完成率/汇总。正向指标、逆向指标、区间目标不能统一套 `实际÷目标`；目标 0、单位冲突、指标改版单列待核实。缺交不是绩效 0；无材料不编造表现。
6. 形成每人证据包：目标→实际材料→证据等级→缺项→待确认。可给行为与结果层面的反馈草稿，不从片段推断人格、健康、忠诚度。评奖、晋升、奖金决定仍由获授权人员作出。

## 输出与验收

输出新的材料目录和汇总表：`收集覆盖`、`证据明细`、`重复与冲突`、`待补材料`、`个人摘要`。确需绩效面谈模板时沿用目标、贡献、证据和下一周期动作结构，不引入强制分布、末位比例或未批准评价标准。

验收：员工×应交周期覆盖可核对；每个数字有出处；没有重复计功；未提供与零值分开；资料不足不输出确定评级。保持原始材料只读，修订另存版本。
